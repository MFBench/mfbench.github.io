# MFBench project website

This repository contains the static project website for **MFBench: Task-specific limits of multimodal AI in urban fire-safety governance**.

## Publish with GitHub Pages

1. Create a public repository named `MFBench.github.io` under the `MFBench` GitHub organization.
2. Upload the contents of this directory to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then save.
4. The site will be available at `https://mfbench.github.io/` after GitHub finishes publishing it.
